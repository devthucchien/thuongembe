# Thương em bé

Trang tĩnh (GitHub Pages) cho Trang Facebook "Thương em bé": trang giới thiệu, chính sách quyền riêng tư, điều khoản
và hướng dẫn xoá dữ liệu mà app Meta "Thương em bé Uploader" cần.

| Trang | Đường dẫn |
|---|---|
| Giới thiệu | `/thuongembe/` |
| Chính sách quyền riêng tư | `/thuongembe/privacy.html` |
| Hướng dẫn xoá dữ liệu | `/thuongembe/privacy.html#xoa-du-lieu` |
| Điều khoản | `/thuongembe/terms.html` |

HTML và CSS thuần, không có bước build, không cookie, không theo dõi.
